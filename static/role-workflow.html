Text workflow

Writer, then Critic, then Organiser. Each press of Run next step sends one model request for the first step that is not completed. The server puts the saved brief and any saved earlier outputs into that request. Nothing is copied between chats by hand. A completed step is not run again. Reloading this page reads the project in the address and does not run a step.

Saved model text is not a reviewed judgement. Read it before you rely on it. Recover marks a step left in running as interrupted and does not call the model.
